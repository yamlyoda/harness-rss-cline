# Message contract

## Брокер

NATS

## Версия

`1`

## Поля

- `schema_version` — версия контракта.
- `link` — обязательный уникальный идентификатор новости.
- `title` — обязательный заголовок.
- `text` — необязательный текст/описание.
- `source` — источник (ria, tass, kommersant).
- `published_at` — время публикации в формате RFC3339.

## Совместимость

- Можно добавлять новые опциональные поля.
- Нельзя менять имена и типы существующих полей без новой версии.
- При переходе на новую версию нужен план миграции и двойная поддержка.
