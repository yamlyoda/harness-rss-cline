# REPORT

## Единый принцип

Контекст дефицитен. Знание живёт в файлах. В контекст подгружается только нужный срез.

## Что сделано

- Корневой `AGENTS.md` стал оглавлением с условными указателями.
- Детали вынесены в `docs/`.
- Сервисы получили локальные `AGENTS.md`.
- Старые `CONVENTIONS.md` и `.clinerules` удалены.
- `docs/` содержит стабильное знание, `memory/` — изменчивое состояние работы.

## Как это работает

- Агент начинает с `memory/active-context.md`.
- При правке контракта получает срез `docs/architecture/message-contract.md`.
- При работе в сервисе получает срез локального `AGENTS.md`.
- После задачи обновляет `memory/`.

## Проверка

Если документ приходится полностью переписывать после рефакторинга, это пересказ кода, а не карта.

Если правило живёт в двух местах, это будущий конфликт.

Если `AGENTS.md` разросся, это кладбище устаревших правил.
