# SETUP

Цель: быстро поднять локальную проверку сквозного потока.

## Минимальный порядок

1. Скопируйте `.env.example` в `.env` и при необходимости отредактируйте переменные окружения.
2. Запустите все сервисы через Docker Compose: `docker-compose up -d`.
3. Примените миграции БД через Alembic (если не применены автоматически).
4. Проверьте здоровье монитора: `curl http://localhost:8000/health`.
5. Принудительный опрос RSS-лент: `curl -X POST http://localhost:8000/refresh`.
6. Убедитесь, что в `news` появляются строки, а в `entities` — сущности.

## Правило

Если команда запуска меняется, не копируй её в корневой `AGENTS.md`. Обнови этот файл.
