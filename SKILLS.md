# SKILLS.md

## Технический стек

- **Язык**: Python 3.12
- **Пакетный менеджер**: UV
- **Форматтер и линтер**: Ruff
- **Фреймворк воркера**: FastStream
- **NER**: SpaCy с русскоязычной моделью (`ru_core_news_sm` / `ru_core_news_md` / `ru_core_news_lg`)
- **Очередь и Postgres**: запуск через `docker-compose up -d`

## Правила работы агента

1. **Форматирование и линтинг**: после каждого изменения кода агент выполняет:
   ```bash
   uv run ruff format .
   uv run ruff check --fix .
   ```
   Все замечания Ruff должны быть исправлены перед завершением шага.

2. **Управление зависимостями**: новые пакеты добавляются через `uv add <package>`.

3. **Безопасность**: секреты и параметры подключения (БД, очередь, API-ключи) хранятся в `.env` / файле настроек (например, `pydantic-settings`). Хардкодить запрещено.

4. **Инфраструктура**: Postgres и очередь запускаются исключительно через `docker-compose up -d`. Ручные установки в коде или скриптах не допускаются.
