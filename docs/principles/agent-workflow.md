# Agent workflow

## Цикл работы

1. Прочитай `memory/active-context.md`.
2. Для значимой правки сначала создай или обнови план в `docs/execution-plans/`.
3. Сделай минимально необходимую правку.
4. Проверь изменение тестами или локальным прогоном.
5. Обнови `memory/progress.md` и `memory/active-context.md`.
6. Если принято новое устойчивое решение, добавь запись в `memory/decisions.md`.

## Правило дублирования

Если одно и то же правило всплыло дважды, вынеси его в `docs/`, а не повторяй в промпте.

## Память

`memory/` обновляет агент. `docs/` обновляется только через осознанный план.

## Обновление памяти

После задачи агент должен явно изменить файлы `memory/`. Это должно быть видно в `git diff`.

## Старые правила

Не создавай и не поддерживай `CONVENTIONS.md` или `.clinerules`. Файл `.clinerules` в корне репозитория удалён. Единая структура — эта документация.
