# Core beliefs

1. PostgreSQL — источник истины, а NATS только транспорт.
2. Дедупликация держится на `news.link UNIQUE`, а не на кэше в памяти.
3. Сообщения могут доставляться повторно, поэтому запись должна быть идемпотентной.
4. Контракт сообщения важнее внутренней реализации.
5. Стабильное знание живёт в `docs/`, изменчивое состояние — в `memory/`.
6. Контекст агенту выдаётся по условию, а не целиком.
7. Технический долг фиксируется явно, а не замалчивается.
