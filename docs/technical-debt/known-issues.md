# Known issues

## 1. Нет повторных попыток при недоступной ленте

Проблема: временный сбой источника приводит к пропуску цикла опроса.

Риск: потеря части новостей при сетевых проблемах.

Почему не чиним сейчас: сначала стабилизируем контракт и поток; правка требует отдельного плана.

## 2. Нет обработки битого XML/контента

Проблема: невалидный RSS-ответ может остановить обработку всей ленты.

Риск: падение всего сбора при получении битого контента.

Почему не чиним сейчас: вынесено в ближайший план `001-add-retry-and-broken-xml.md`.

## 3. Загрузка модели spaCy дольше таймаута healthcheck

Проблема: загрузка модели `ru_core_news_sm` занимает время, сервис может считаться неготовым во время инициализации.

Риск: ложные перезапуски контейнера оркестратором.

Почему не чиним сейчас: нужен отдельный дизайн readiness и liveness probes.

## 4. Опрос только по расписанию, нет реактивности

Проблема: опрос раз в 5 минут, нельзя получать новости мгновенно.

Риск: задержка в получении свежих новостей.

Почему не чиним сейчас: RSS по своей природе pull-модель; для push нужен другой протокол (например, WebSub).
