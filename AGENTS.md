# AGENTS.md

## Проект

`rss-cline` — event-driven система мониторинга новостей из RSS-лент (РИА, ТАСС, Коммерсантъ) с извлечением именованных сущностей через spaCy.

## Состав

- `monitor/` — FastAPI-сервис, опрашивает RSS-ленты раз в 5 минут и публикует новые записи в NATS.
- `worker/` — FastStream-сервис, потребляет сообщения из NATS, запускает NER (spaCy `ru_core_news_sm`), записывает результат в PostgreSQL 16.
- `alembic/` и `migrations/` — миграции схемы БД.
- `docs/` — стабильное знание о системе.
- `memory/` — изменчивое состояние текущей работы агента.
