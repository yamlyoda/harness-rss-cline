# Architecture overview

## Поток данных

RSS-ленты (РИА, ТАСС, Коммерсантъ) → `monitor/` (FastAPI, опрос раз в 5 минут) → NATS → `worker/` (FastStream + spaCy `ru_core_news_sm`) → PostgreSQL 16.

## Ответственность

- `monitor/` знает только входные ленты и публикацию сообщений в NATS.
- `worker/` знает только подписку на NATS, обработку NER и запись в БД.
- NATS — транспорт, не хранит бизнес-истину.
- PostgreSQL — источник истины по новостям и сущностям.

## Где что лежит

- `monitor/` — входная точка сбора (FastAPI).
- `worker/` — обработчик очереди (FastStream).
- `alembic/` и `migrations/` — миграции схемы БД.
- `docs/architecture/` — карта связей.
- `docs/design-docs/` — причины решений.
